# Governance

KARTAL Runtime is an independent open-source research project maintained by
Kartal Derin.

## Decision model

The project currently uses a maintainer-led model. Technical decisions are
evaluated against four priorities:

1. verifiable auditability;
2. safe action-boundary enforcement;
3. framework and model independence;
4. reproducible evaluation.

Major design changes should be proposed in a public issue before implementation.
The proposal should state the problem, alternatives, compatibility impact,
security implications, and an evaluation plan.

## Research claims

Benchmarks, papers, and public claims associated with KARTAL must identify the
tested version, dataset or scenario set, baseline, metric definition, and known
limitations. Results should be reproducible from public artifacts whenever
licensing and privacy constraints allow.

## Contributions

Pull requests require tests for behavioural changes and documentation for public
interfaces. Acceptance does not imply endorsement of unrelated products,
institutions, or research claims.

## Institutional collaboration

Universities, research laboratories, public-interest organizations, and industry
teams may propose adapters, benchmark scenarios, independent evaluations, or
joint research. Collaboration does not transfer project ownership unless a
separate written agreement explicitly states otherwise.
