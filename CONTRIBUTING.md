# Contributing

KARTAL welcomes focused contributions to auditability, policy enforcement, failure recovery,
framework adapters, and process-level evaluation.

1. Open an issue describing the problem and proposed behavior.
2. Create a small branch with tests for the change.
3. Run `python -m unittest discover -s tests -v`.
4. Keep public APIs typed and model-independent.
5. Do not log secrets, personal data, or hidden chain-of-thought content in examples or tests.

By contributing, you agree that your contribution is licensed under Apache-2.0.
